## Overview
Since this project involves two separate actuators along with a sensor and a display, making a power budget is essential to make sure there is enough power
for all the components to operate safely.

![power budget](Power_Budget.png){style width:"350"}

## Conclusions

From the power budget, it was determined that the rated current draw of the two actuators is fairly low, leaving plenty of headroom with the selected power supply and voltage regulator. Running the actuators off the input 9V power line moves current off the linear voltage regulator and reduces heat dissipiation.
